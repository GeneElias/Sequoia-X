# 两市研究与模拟组合看板

## 放在哪里

| 方式 | 优点 | 约束 | 本项目建议 |
|---|---|---|---|
| GitHub Pages 静态页 | 无应用服务器，交互图表灵活，能复用当前Python报告；符合零预算原型路线 | 通常公开可访问，不适合直接放完整私人持仓；Pages可用性取决于GitHub套餐和仓库类型 | 看板前端首选，先公开虚构演示，真实数据仅本地导出 |
| 飞书多维表格/仪表盘 | 群内阅读、租户权限、手机协作方便 | 需建表、应用授权和数据同步；自定义图表及额度取决于租户版本 | 需要仅群内可见时更适合，但要额外接入 |
| 飞书机器人卡片 | 已有推送机制，上手简单 | 消息不是持续交互的数据看板 | 保留为日报/周报通知与看板入口 |

建议组合：**静态看板 + 飞书通知**。如果要求真实账本只给群成员看，优先飞书表格/看板，或使用有访问控制的托管环境，而不是默认公开的GitHub Pages。前端公开与代码仓库是否私有是两个不同问题，不能靠隐藏网址、robots.txt或不公开源码实现访问控制。

本轮没有公开发布真实数据，也没有修改飞书租户或建立外部应用。

## 当前可用

```bash
# 仓库根目录，零新增依赖、零外部请求，只读现有报告和模拟账本
.venv/bin/python -m sequoia_x.reporting.dashboard
```

输出 `reports/dashboard/index.html`，一个文件即可离线打开；同目录 `dashboard.json` 是经过字段白名单筛选的快照。支持两市切换、收益曲线指标与日期范围、股票搜索/筛选/排序、持仓、最近500笔模拟订单、每周复盘和单市场快照下载。UI中的价格/收益缺失值不会补零，两市不会合并币种。

页面没有CDN、字体服务、统计脚本、实时联网请求或第三方JS依赖。凭证、原始SQLite文件、估值私人备注、Webhook及原始错误正文不会被嵌入；用户文本以textContent渲染，内嵌JSON防止script闭合注入。

每日/每周模拟任务结束后自动重新导出看板。页面是静态快照，刷新只会取得已经重新生成的文件，不会自行跑选股或刷新行情。心跳只表示导出时记录，不保证当前进程在线。

当前真实账本没有合格推荐和成交，展示空仓/无投入，收益率留空。另有虚构演示模板可体验曲线交互，明确标演示：

```bash
.venv/bin/python -m sequoia_x.reporting.dashboard --demo --output reports/dashboard-demo
```

## GitHub Pages 演示部署准备

已提供 `.github/workflows/dashboard-demo.yml`。它只允许手动触发，并且固定使用 `--demo`，不会读取真实账本或发布真实股票、持仓、收益。Python标准库即可构建，不需要Webhooks、行情密钥或安装金融SDK。

将经审阅的代码推送到所需仓库后：

1. 在仓库 Settings → Pages 中选择 GitHub Actions 构建来源（须有权限，且套餐/仓库类型支持Pages）。
2. 在 Actions 手动运行“Deploy dashboard demo (no real portfolio data)”。
3. 查看该workflow返回的实际页面地址，不自行拼接或假设部署成功。

**当前实际部署路径（2026-10-24）**：预构建的虚构演示站点已推送到 `GeneElias/Sequoia-X` 的新 `gh-pages` 分支，提交 `668b933417bee3eeea64ae6f6a0f39008d79b3a2`。此路径应在 Settings → Pages 选择 **Deploy from a branch → gh-pages → /(root)**，不需要合并到master，也不需要运行上面的可选Actions工作流。

GitHub管理API和站点域名被当前平台代理拦截，因此无法确认Pages已启用或页面已上线，没有已验证的部署URL。真实报告与账本未上传。具体飞书配置见 [飞书接入步骤](feishu-setup.md)。

若后续要公开真实快照，应先明确允许公开的字段和数据供应商的展示权限。真实 `reports/` 已在 `.gitignore` 中，不应整目录提交；更不能把 `.env`、原始账本、发送记录或私有研究资料上传到Pages。当前workflow故意不自动转换成真实组合发布任务。

GitHub Pages只托管生成后的文件，不会让当前云环境保持运行，也不会自动取行情。每日推荐和模拟账本仍依赖当前常驻进程或另行部署的可靠调度服务；不能把网站在线当成每日任务正在执行。

## 飞书入口

真实部署并取得HTTPS地址后，可在飞书卡片加按钮或群内置顶该地址；不能把本地文件路径或localhost地址当作群成员可访问的网站。Webhook仍使用本地安全配置，不能嵌入静态网页。若选择飞书原生看板，需要后续提供目标表格/空间和应用授权，当前没有相关凭证或配置。
