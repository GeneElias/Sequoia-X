# A股与美股：每日100股模拟买入、每周复盘

这是本地模拟账本，不使用券商接口，不读取券商凭证，不投入真实资金。

当前生产执行已准备迁到GitHub Actions，见 [GitHub部署说明](github-actions.md)。云环境标记为`github_active`后，旧本地账本拒绝继续写入，防止双端运行；以下本地命令用于独立开发账本，不应在迁移后的旧副本上继续下模拟单。

## 策略口径

- 两市都做，人民币(CNY)与美元(USD)独立核算；不将不同币种收益直接相加。
- 只模拟当天报告里**通过量价确认且估值有安全边际**的买入研究候选。每市每天最多10支，每只100股。观察项、资料不足、估值待核验、质量否决不买；不为了产生收益数字强行交易。
- 同一股票不同交易日再次推荐，再买100股；同日重跑不重复登记。拆股后的总持股数可以不再是100的整数倍。
- 信号来自完整收盘数据，模拟成交安排在**下个当地交易日开盘**。不会用当天开盘价成交当天收盘后才产生的信号。
- 当前使用买入并持有，不自动卖出，不在周末清仓。因此周报中的盈亏是持仓价格收益，不是已实现利润。
- 没有固定虚拟本金上限，每次成交注入足够的虚拟资金；它衡量持续追加资金的策略表现，不等于一笔固定本金账户的收益。
- 买价=开盘价×(1+0.0005)，即默认5bp滑点；模拟每笔手续费默认0。投入成本包含费用，收益不含股息和税费，**不是总回报**。这些假设并不代表真实券商收费或可实现成交价。
- 订单错过下一成交日就过期，不在恢复运行后按过去价格补单。当天取数失败留待补数据，过了当天仍未取得有效数据则过期。
- 停牌/零成交量不成交；A股一字上涨日保守假设不可成交；科创板首笔最低200股与固定100股冲突，因此不成交。非一字涨停也不保证真实可成交。
- 按Yahoo披露的拆股事件调整已有持仓，重复运行不重复拆股。缺少原始开盘价/拆股历史或最新持仓价格时，收益标“待核验”，不会用零价格记亏损或沿用旧价冒充最新收益。未覆盖全部复杂公司行动（配股、分拆、换股、退市清算等），发生时需人工核账。

## 命令

仓库目录 `/workspace/Sequoia-X`：

```bash
# 两市生成日报，结算已有订单，登记新信号；默认只预览
.venv/bin/python -m sequoia_x.reporting.simulation daily

# 本周复盘（默认最近一个周五），刷新已有持仓估值，不生成新信号
.venv/bin/python -m sequoia_x.reporting.simulation weekly

# 生成并发送；没有Webhook会保留报告并标记 blocked_missing_webhook
.venv/bin/python -m sequoia_x.reporting.simulation daily --send
.venv/bin/python -m sequoia_x.reporting.simulation weekly --send
```

默认读取 ignored 的 `valuations.local.json`，无文件时估值待核验、无买单。可用 `--valuations` 指定其他已复核输入。模板和复核要求见 [研究报告说明](research-reports.md)。不能把演示估值或当前无材料的观察项当作推荐。

账本在 `reports/_state/paper.sqlite`，订单、成交、持仓和每日快照都保留。删掉此文件等于重置模拟组合。不要从不同程序或未来数据直接篡改其日期。修改滑点/手续费假设需指定新的 `--root` 使用独立账本，不能在同一收益序列中悄悄改变成本政策。

输出：

- `reports/paper/daily/<行情日>-A/` 与 `...-US/`：日报、卡片、模拟状态。
- `reports/paper/weekly/<周五日期>/review.md`：周复盘。
- 同目录 `review.json` / `cards.json`：结构化周数据和可发送卡片。
- `reports/_state/delivery.sqlite`：发送去重及未知状态保护，沿用原报告机制。

**周收益口径**：

`周价格盈亏 = 周末市值 - 上周末市值 - 本周新增虚拟投入`

`周收益率 = 周价格盈亏 / (上周末市值 + 本周新增虚拟投入)`

这是披露了资金追加的简单期间收益率，不是时间加权、资金加权IRR或年化收益率。新注入资金不会被当作盈利。无投入时收益率不计算；之前已有持仓但缺少上周末完整快照时，周收益显示待核验。周末以该周当地最后交易日估值，节假日不假设有交易。

## 定时运行（上海时间）

| 任务 | 时点 |
|---|---|
| A股日报、已有模拟订单结算与新信号登记 | 周一至周五17:00 |
| 美股日报、已有模拟订单结算与新信号登记 | 周二至周六07:30（对应前一美国交易日） |
| 两市每周复盘 | 周六09:00 |

交易日历另外检查节假日、夏令时和提前收盘。假日出现同一行情日不会重复下单。程序每分钟检查一次当日到期任务，用SQLite记下已执行任务。同日失败任务不无限重试；修复网络或数据后可手动执行daily/weekly。中断的running任务保留6小时租约后才允许重新执行。

```bash
# 前台进程，Ctrl-C停止；--send只在配置Webhook后真正发群
.venv/bin/python -m sequoia_x.reporting.simulation daemon --send

# Linux单实例启动脚本（flock确保不重复启动），可用nohup后台运行
bash scripts/run-paper-scheduler.sh
```

心跳：`reports/_state/scheduler-status.json`；任务记录：`reports/_state/schedule.sqlite`。后台日志可以重定向到 `reports/_state/paper-scheduler.log`。

**云环境限制**：定时进程仅在这台环境保持运行时有效；环境暂停、重建或进程终止后，不会自动唤醒，也不能保证漏掉的交易日全部执行。需要每日不间断运行时，应部署到用户自己的常驻机器或可靠托管调度服务。启动说明会提示未来云任务检查并恢复进程，但这不等于平台具备自动定时唤醒能力。

飞书仍需本地 `.env` 中的 `FEISHU_REPORT_WEBHOOK_URL`（或原默认URL），可选 `FEISHU_REPORT_SECRET`。凭证不要发到聊天或提交Git。缺少Webhook不影响模拟账本和本地日报/周报，但不会发送消息。定时进程会在每次任务前重新检查本地配置，补齐后后续任务可发送；旧报告可用原 `--send-existing ... --send` 命令手动发送。

2026-10-30更新：自动核验财报与独立的净现金股东现金流估值模型已接入日报；不会伪造人工复核。除原有重复订单保护外，GitHub补检以加密任务回执按交易日去重。登记信号时还检查下一交易日实际开盘时间，迟于该开盘的信号不登记、不事后按开盘价补买。买入数量仍为每支合格候选100股、每日最多10支、下一交易日开盘模拟执行。
